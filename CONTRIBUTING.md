This repository is a set of `asv` benchmarks for Array API Standard compliant libraries. It is tested by running it against [`array-api-strict`](https://github.com/data-apis/array-api-strict/).

As such, a basic understanding of the [Python Array API Standard](https://data-apis.org/array-api/latest/) as well as [Airspeed Velocity](https://asv.readthedocs.io/en/stable/) is desired.

To contribute to this repository, please open a PR. All types of contributions are welcome, but the following are particularly appreciated:

* New benchmarks for higher-level operations.
* Documentation
